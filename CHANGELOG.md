# Changelog

All notable changes to this plugin. Versions follow [semver](https://semver.org) and
must match `.claude-plugin/plugin.json`. **Bump the version on every change you want
members to receive.** Claude Code uses it as the update cache key, so an unchanged
version means members get nothing when they click Update.

- **MINOR** (`1.0.0 -> 1.1.0`): new skill(s) added
- **PATCH** (`1.1.0 -> 1.1.1`): fix to an existing skill
- **MAJOR** (`1.x -> 2.0.0`): breaking change (skill renamed/removed, behavior users rely on)

## [1.0.0] - UNRELEASED
- Initial plugin.
